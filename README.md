# 우리는교회 목회팀 (홈 화면 앱)

- `index.html` : 앱 화면 전체(GitHub에서 바로 뜹니다). 데이터는 구글 앱스 스크립트(/exec)에서 받아옵니다. 처음 실행 때 /exec 주소를 한 번 입력하면 기기에 저장됩니다. 주소를 바꾸려면 주소 뒤에 `?reset` 을 붙여 열어 주세요.
- `manifest.json`, `sw.js` : 홈 화면 설치 + 빠른 시작용
- `icons/` : 앱 아이콘
- `legacy.html` : 예전 방식(구글 화면을 전체 화면으로 감싸는 껍데기). 문제가 있을 때 임시로 사용
